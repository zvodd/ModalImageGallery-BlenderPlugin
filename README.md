
An operator that overlays a gallery of the blender file's images in the Image Editor and UV Editor. Select images by sight with thumbnails that are larger than 20 pixels.

Can be found in the Image Editor toolbar under View -> Image Gallery Overlay. 
Only available in the Image Editor / UV Editor.

### Usage

Launch modal, navigate with scroll, click an image to switch to it.

In the UV or Image Editor, can be found launched in the toolbar  `View` -> ` Image Gallery Overlay`

The operator can also found in the Search Menu <kbd>F3</kbd> under `Image Gallery Overlay`

**Note**: Right Click the menu item and `Add to Quick Favourites` will add it the to <kbd>Q</kbd> key menu.
#### Controls

| Binding                                  | Action         |
| -----------------------------------------| -------------- |
| <kbd>Right Click</kbd> / <kbd>Esc</kbd>  | Cancel Modal   |
| <kbd>Left Click</kbd>                    | Select Image   |
| <kbd>Mouse Wheel</kbd>                   | Scroll Gallery |
| <kbd>Ctrl</kbd> + <kbd>Mouse Wheel</kbd> | Zoom Gallery   |
